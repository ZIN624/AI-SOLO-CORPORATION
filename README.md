# AI一人会社 スターターキット

社員0人・AI社員10人で会社を回すための、Claude Code 用テンプレートです。

---

## 何が入っているか

```
CLAUDE.md              会社の基本方針（全AI社員が毎回読む就業規則）
.claude/agents/        AI社員10人の職務記述書
docs/playbook.md       日々の運用の型・定期実行の設定方法
work/                  日々の成果物（日付ごとに保存）
data/                  分析用の元データ・各種台帳
```

## 使うツールの対応

元ネタの構成を、Claude Code で実際に動く形に置き換えています。

| 元の構成 | このキットでの実装 |
|---|---|
| Claude Projects | `CLAUDE.md` + `.claude/agents/`（git 管理されるので履歴が残る） |
| Perplexity | 内蔵の WebSearch / WebFetch |
| Canva | Figma MCP / HTML・SVG での直接生成 |
| Zapier | Routines（定期実行）+ Gmail・Google Drive MCP |
| Excel | `xlsx` スキル（内蔵） |

## 始め方（10分）

### 1. 手元に持ってくる
```bash
git clone https://github.com/ZIN624/AI-SOLO-CORPORATION.git
cd AI-SOLO-CORPORATION
```

### 2. ★最重要★ 会社概要を書く
`CLAUDE.md` の「1. 会社概要」の表を、自分の事業の内容に書き換える。

**ここが空だとAI社員は全員的外れな仕事をします。** 唯一の必須作業です。

### 3. 起動する
VS Code でフォルダを開き、ターミナルで:
```bash
claude
```

### 4. 最初の一手
```
ceo と marketer に、この事業で最初にやるべきことを検討させて
```

### 5. 慣れてきたら
`docs/playbook.md` を読む。日次・週次の型、定期実行の設定方法、業務のマニュアル化（スキル）の作り方が書いてあります。

---

## 進め方の推奨

いきなり10人使わないこと。

1. **researcher / writer / programmer** の3人から始める
2. 毎回同じ説明をしている業務が出てきたら `.claude/skills/` にマニュアル化する
3. 手順が安定したものだけ定期実行に乗せる
4. 業務が増えてから他の社員を足す

---

## 注意

- **外に出るもの（メール送信・SNS投稿・公開・課金）は必ず人間が最終確認する。** 各社員の定義にもそう書いてあります。
- APIキー・顧客の個人情報はリポジトリに入れない（`.env` を使う。`.gitignore` 設定済み）。
- 「10人雇えば勝手に回る」のは *手順が決まっている作業* だけ。意思決定・顧客との信頼・品質の最終責任は人間に残ります。
